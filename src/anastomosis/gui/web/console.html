This console runs inside the desktop app. Launch it with anast gui (needs the anastomosis[gui] extra).
This console inspects an existing upload ledger and can drive the resumable upload engine against a browser YOU launched and logged into.
Press Cmd/Ctrl+K for the item-key palette (encounter id + content hash — never patient names). Press L for the activity log.

drive an upload

Run the verification ladder around each upload (ON by default; needs the render extra and refuses to run without it). Unchecking files WITHOUT the ladder — the wrong-patient banner check is always on, verified or not.
The output directory above (manifest + ledger) is the upload source. A re-start resumes a prior run; already-filed items are not re-driven.
